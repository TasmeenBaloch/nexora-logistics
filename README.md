# NEXORA Logistics

A premium, responsive logistics business website designed to present logistics and supply chain services through a modern and professional web interface.

## Project Overview

NEXORA Logistics is a multi-page business website created as an individual web development project. The website focuses on clean design, responsive layouts, interactive JavaScript features, and a professional logistics brand experience.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Multi-page website with consistent navigation
* Premium logistics-focused visual design
* Interactive hero section
* Shipment tracking functionality
* Contact/enquiry form with client-side validation
* Animated statistics
* Service showcase section
* Company information and process sections
* Call-to-action sections
* Mobile-friendly layout

## Website Pages

* **Home** — Introduction to NEXORA Logistics, services, statistics, and company highlights
* **About** — Company information and reasons to choose NEXORA
* **Services** — Logistics and supply chain services
* **Tracking** — Shipment tracking interface
* **Contact** — Enquiry and quote request form

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the website using a local development server such as VS Code Live Server.
